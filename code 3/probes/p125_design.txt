P125 预登记 —— 给"每单元付一次的那一段"定价（prologue / epilogue 双臂）
=====================================================================

立论来源（不改）：`#15.103` P123+P124 两把尺子合解 ⇒ **平台每 chunk 平均只填 ≈6.6 个 token**
⇒ 全部"每 chunk 固定税"的读数要**改读成"每单元"** ⇒ 那 ≈70 % 无价的落点是
**每单元一次的 I/O + 单元数本身**。单元数那半边已有单价（P126/P127，两侧不对称）；
这一发问的是**另外那半边**：一个单元"开工前 + 收工后"这两段到底值多少墙。

⚠️ 这是**计量器**不是杠杆：读到的数本身不涨分，它的价值在于"如果 prologue+epilogue 值
X %，那少付一次的写法（合并单元 / 让 prologue 跨单元复用）值多少"。**判据在下面第 5 条**。

1. 靶子（`op_kernel/sparse_flash_attention.cpp`，一个单元 = 一个 (head-block, shard)）
   - **prologue**：L456 `LoadQ(...)` + L459-461 三条 `Duplicate`（o 清零、m=MIN、l=0）。
     `LoadQ` 体内 = 每 `stageMax_` 头一组：两条 `CopyGm2Ub`（content / rope）+ 一对
     `MTE2_V` 旗标 + 逐头两条 `WidenToF32` + 一对 `V_MTE2` 旗标。
   - **epilogue**：L555 `WriteOut(...)` 的**尾巴**（`SetFlag/WaitFlag(V_MTE3=1)` +
     `CopyUb2Gm` + `MTE3_V=1`，以及 `lseOn_` 那一对 `DataCopyPad` + `V_MTE3/MTE3_V=2`）。

2. 幂等性（这是这一发能不能成立的全部理由，逐条查过）
   - **prologue 整体幂等**：`LoadQ` 是"GM→UB→(Cast)→UB"的纯函数，源地址（`qGm_+s1Base+…`、
     `qrGm_+ropeBase+…`）与目的（`kb`/`kr`/`q[i0+t*qRow]`）在重复调用之间都不变，且此时
     `kb`/`kr` 还没被 KV chunk 覆盖（覆盖发生在后面的 while 循环里）⇒ 重跑 N 遍写下的字节
     与跑一遍**完全相同**。`Duplicate(o/ml/ml[halfOff_])` 同理（常量写、不读回）。
     ⇒ 这一臂**不需要**P121 那套"只重读地址 + 不可达 sink"的构造。
   - 🔴 **`WriteOut` 整体不幂等**：它对 `o` 做**原位** `Muls(oi, oi, 1.0f/l)` ⇒ 跑两遍等于除
     `l²`。⇒ epilogue 一臂**只重复 DMA 尾巴**（从 `st` 读、往 `outGm_`/`maxGm_`/`sumGm_` 写，
     重复写同一批字节），`Muls`/`PackFromF32`/`GetValue` 那几行**一遍都不多跑**。
     这两行不改 `st`、不改 `o`，所以重复段是自足的：旗标 id 1/2 的 Set/Wait 成对出现在重复体内。
   - 两臂各自的"数值不变"是**可证**的，但照旧要过本地逐位门（下面第 4 条），不靠证明放行。

3. 臂定义（同一份 kernel 基线，各自 ×N；N 由本地标定挑，见第 4 条）
   - `p125q`：把 L456-461 那一段包进 `for (int rep = 0; rep < N; ++rep) { … }`。
   - `p125w`：把 `WriteOut` 内两段"旗标 + `CopyUb2Gm`/`DataCopyPad`"各包进同样的 `rep` 循环。
   - ⛔ 提交字节里不许留 `printf`/`TODO`/`#if 0`；重复倍数走**编译期常量**（`static constexpr
     int kP125Rep = N;` 那种），不许读环境变量。发货前 `grep -c` 命中数当门。

4. 本地标定（必经，P121 立的规矩：不给防 CSE 的那一项，N=3 与 N=1 同一份机器码）
   - 阶梯 N ∈ {1, 2, 4, 8}，同机同次构建，七例（p1 p2 p4 p6 big1 w3 r64c65）时间曲线
     ⇒ 要求 **log-线性**（每翻倍增量近似）；若 N=1 与 N=2 时间差 <0.3 %，说明被 CSE/管道
     吸收了 ⇒ 这一臂作废、不发货。
   - 数值门：`p32_gate.sh` 26 例双 dtype **超差全 0** + 逐位与 pristine 同（`SFA_F32=1` 那份也是）。
   - 参考单价：状态板 §4 那四条（碎拷贝 ≈50 ns/条、Fixpipe ≈0.7 µs/条、标量 GM 读 38.6 ns、旗标对
     ≈0.42 µs/轮，`LOG#15.70`）**是 AIC 侧的读数**，不能直接乘到这一段上 —— `LoadQ`/`WriteOut`
     跑在 MIX 1:2 的**向量核**上，而 AIV 侧条数单价实测 **8~12.3 ns/条**（P115）。
     ⇒ 这一段的先验**只能给到"每单元几 µs 以内"**，跨不到墙钟占比；占比本来就是这一发要问的东西。
   - ⇒ **N 由本地标定挑，不由先验挑**：取"本地 Δ ≤ +15 %"里最大的那一档（约定同 P119 ×2 /
     P121 ×7 / P123 ×63 —— 让重复段留在次要效应之前），并把这个 N 写回本文件再发货。

5. 判据（预登记，读的时候不许改口径）
   - Σ Δ ≥ +6 % ⇒ prologue/epilogue **有价** ⇒ 这才第一次给"每单元一次的 I/O"钉上真单价，
     并立刻折算"合并单元能省多少"（那才是下一发）。
   - Δ 落进 Σ ±2 % 噪声带 ⇒ **按已定口径关闭这根杠杆**（P120/P121 的判法：带内 = 一发关闭、
     不补枪）⇒ 那 ≈70 % 里"每单元 I/O"这个落点也判空 ⇒ 剩下的候选只剩"每单元没填满就得收工"
     这件事本身（chunk 数 = ⌈6.6/48⌉ 的浪费 ⇒ 那是 **n_blk 与 fill 的匹配**，不是任何一段代码）。
   - 🔴 若某一臂**逐点**出现正负分裂（P127 教的），单点读数必须**两遍同字节复现**才许引用。

6. 顺序
   - P125 排在 **P128 之后**（P128 是纯 host 三行、且是"留住已测到的 −7~−13 %"的护栏，
     收益方向已知；P125 是测量）。两发都要花提交，但提交不限 ⇒ 按 EV 排。
   - ⚠️ 429 退避 ≥8~10 min（`#15.105` 订正）。
