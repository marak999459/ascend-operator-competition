P123 设计预注册（发前写死，防止读完再挑口径）
================================================

立论位置
--------
(a) 同核旗标对（P120，≤0.076 %/chunk）、(b) 标量下标扫描（P121，≤0.29 %）、(c) 跨核 barrier
（#15.101 静态关闭）全部出局之后，§1.1 那 ≈71 % **不再有任何具名机制挂着**。八把尺子的共同
形状是"多干一份同样的活"，它们读到的是**边际发射成本**；唯一没被这一族碰过的东西是
**依赖 / 等待**——复制体可以躲在影子里，链不能。这一发就是去问链。

为什么这一发与 P119 只差一个变量
--------------------------------
P119：复制 PV 那段 `Axpy`，目的端换成 `kfBuf_` 末行 ⇒ 指令类/宽度/条数全同，**但没有依赖**
      ⇒ 平台 **Σ +2.9 %**（这就是"加一份 PV 的发射成本"的平台价）。
P123：在同一个函数尾部追加 N 圈 `Muls(o_i, o_i, 1.0f, rowC)` ⇒ 同指令类（向量乘）、同宽度
      （rowC = D_ 个 fp32）、同目的端（**真累加器**）、逐位恒等（`x*1.0f`，本仓库 L347/L360
      的透传就是靠它）⇒ 唯一差别 = `dst == src` ⇒ N 圈彼此排队、且下一 chunk 的 PV 必须等它。

零假设的算术（必须先写下，否则读数出来再算就是事后拟合）
--------------------------------------------------------
每 chunk 基线 V 指令 ≈ PV 的 m×nbCur 条（rowC 宽）+ 重缩放 nbCur 条；计量 = N×nbCur 条同宽 Muls
⇒ **指令数比 = N/m**。平台 m（= 每 chunk 的 token 数 = `n_blk`）按 P92 那句"实测 k 恒 64"取
m = 64，保守带 m ∈ [32, 64]。选 **N = 63** ⇒ 比值 1.0~2.0 ⇒ 按 P119 那个"加一份 PV = +2.9 %"的
平台锚点，**零假设 = Σ +2.9 % ~ +5.8 %**（±2 % 的 Σ 带 ⇒ 与 0 勉强可分、与链假设完全可分）。

链假设的预言
------------
若 V 管不能靠 nbCur 路交错把 RAW 距离藏掉，每圈要付一次 `Muls`(rowC 宽) 的**完整延迟**（不是
吞吐份额）。本地四臂给的是吞吐价（0.35~0.6 %/圈），链价的量级要看平台，预言形式取"≥ 零假设
的 3~5 倍"= Σ ≥ +12 %。

判据（发前写死）
----------------
- Σ ≤ +8 %   ⇒ **吞吐型**：依赖不是钳子（与 P119 同一个结论方向，但这一发把它从"推断"变成"测过"）。
- Σ ≥ +12 %  ⇒ **链型**：双累加器交错（每 chunk 自依赖深度 1 拆 2、指令数不变）第一次有了靶。
- 8~12 %     ⇒ 不定 ⇒ 只读逐点形态（六点若分歧 ≥20 pp 说明与 nbCur 相关 ⇒ 回来对 §5 #20 的口径），
               **不补第二发**（§1.2：两发单遍探针之间 <5 pp 不可判）。

三个已知混淆（都往"死读数"那一侧偏，因此"死"要有代价折扣）
----------------------------------------------------------
① 依赖距离 = nbCur：若平台每组的头数大，N 圈会被交错藏掉 ⇒ 死读数有两种成因（链不是钳子 /
   链被藏住了）。本地可以用小 nbCur 档排除后者，平台上不行 ⇒ 死读数只当"不是大杠杆"，不当"不存在"。
② N=63 会让这份计量在 V 管里与 PV 同量级 ⇒ 若平台 V 已饱和，读数会**超线性**。这一条是本地
   0/7/31/63 四臂线性检验存在的理由：**本地非线性就不发货**（P92b 那条饱和曲线就是在大 N 才现形的）。
③ 计量圈在 chunk 边界内 ⇒ 与"每 chunk 固定税"那根轴有耦合；P120 已经给出旗标侧 ≤0.076 %/chunk
   的不利上界，所以这条耦合最多贡献零头。

发货前置（硬性）
----------------
1) 本地四臂 ARMS=0/7/31/63：Δ ∝ N（31/7 期望 ≈4.4、63/7 期望 ≈9，容差 ±25 %），且 8 档
   out/max/sum 对一次性 golden_p123/ 全 `逐位一致`。不满足 ⇒ 尺子不成立，这一发作废。
2) §7.5 链：p123_probe.sh 闸门 → 最后一次 npu.sh sync（此后不 build）→ 四枚当场 sha256 本地/远端
   逐个吻合 → SOCEDEX=0 / RESIDUE=0 / FORBID=0 → dry-run → submit → 读六点 → p123_reissue.sh 回发。
